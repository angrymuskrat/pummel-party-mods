# Pummel Party Mod Editor — справочник

Редактор встроен в игру: главное меню → Workshop → Mod Editor. Интерфейс как у Unity Editor (иерархия, компоненты, инспектор, плейтест, публикация). Скриптового языка нет: логика — это Action Editor, где действия срабатывают на события мини-игры или на попадание игрока на кастомную клетку доски и выполняются последовательно; сетевую синхронизацию делает движок. Тип мода (мини-игра или доска) выбирается при создании и не меняется. Новые предметы, персонажи и глобальные правила редактор не трогает.

## Файлы справочника

| Файл | Что там | Когда читать |
| --- | --- | --- |
| `reference/logic-catalog.md` | все события, действия с параметрами, компоненты, условия, ограничения — с URL страниц вики | любая задача про механику: «как сделать X», разложение идеи на цепочки |
| `reference/editor-workflow.md` | создание проекта, интерфейс, доски, мини-игры, импорт ассетов, префабы, плейтест, валидатор, публикация, где лежат проекты | задачи про сцену, ассеты, отладку, публикацию |
| `reference/scene-format.md` | бинарный формат `MainScene.scene`/`.pfab`, `.pmeta`, материалы, коды действий и триггеров, схема компонентов | генерация или правка модов кодом через `tools/pmscene.py` и `tools/pmgen.py` |

Читать только нужный файл, целиком; каталог большой.

## Как отвечать

1. **Механика → цепочка.** Для каждой механики выписать таблицу `Событие | Действия по порядку | Параметры` только из имён каталога. Нет подходящего действия — написать «в редакторе нет; замена: …» или «по вики не подтверждено».
2. **Сначала самая простая цепочка.** Если механика собирается двумя действиями, не предлагать пять.
3. **Ассеты** — проверить формат и ограничения в `editor-workflow.md` до того, как генерировать файл.
4. **Скриншот Log Window / Mod Validator** — переписать текст ошибки, найти упомянутый компонент или действие в каталоге, назвать самую вероятную причину и один шаг проверки.
5. **Ссылки.** При ответе давать URL страницы вики, откуда взят факт.

## Обновление справочника

Если вики изменилась (новый патч игры) — перезапустить сбор `reference/` агентом с полным обходом `Special:AllPages`, а не править вручную отдельные строки. В начале каждого файла `reference/` стоит дата сбора.

## Что не делать

- Не водить редактор через computer use без явной просьбы: сборку сцены мышкой делает пользователь.
- Не публиковать в Workshop и не запускать игру самостоятельно.
