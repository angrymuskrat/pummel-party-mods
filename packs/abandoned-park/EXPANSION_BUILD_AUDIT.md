## Выполненные проверки

Повторяемая команда для установленных проектов:

```powershell
python packs/abandoned-park/minigames/check_expansion.py
```

Для другого каталога сборок передать его первым аргументом.

- Сцены и префабы читаются и сохраняются побайтно без потерь; GUID уникальны, ссылки на сцену, префабы и ассеты разрешаются. JSON настроек читается.
- Восемь отдельных спавнов, маски участников 255; прыжки, кулак и имена выключены. Расписания укладываются в лимит.
- У 104 заданий проверены ответы и единственный максимальный балл. Для теней независимо пересчитаны проекции четырёх объёмных альтернатив при четырёх поворотах; для парада пересчитаны признаки фигур, для проводов пройден путь по перестановкам.
- Ответ переносит игрока в изолированный отсек и блокирует движение. Сплошная перегородка закрывает пеший доступ к зоне оценки. Очки в пяти викторинах выдаются только после закрытия всех ответов. Каждый этап имеет собственные одноразовые триггеры.
- В котле приз выдаётся сразу; личная защёлка CashLatch закрывается до начисления. Последующая смена ступени её не открывает. Авария отключает общего родителя касс, поэтому дочерняя ступень не может вернуть получение приза после аварии.
- По игровым типам ModTrigger, ModLogic, SpawnPrefabAction, ModAssetReference и SimpleModPlayerSettings проверены One Use Per Player, On Stay, обработчик Enable, отложенное разрешение ссылок и showNameTags. Logic и Trigger не совмещены на одном объекте.
- Осмотрены планы сверху, отдельные кабинки, силуэты и образцы карточек. Для планов используется копия сцены с включённым первым вариантом; поставляемая сцена сохраняет управление по расписанию.

## Границы и следующий плейтест

Это первые версии механик. В Counterfeit Mascots используются изображения и два вида отличий. В Crossed Wires пока только целые провода; задачи с разрывами остаются расширением. Банк из четырёх вариантов на этап можно запомнить.

Приоритет: Mod Validator, полный раунд и повторный запуск; затем хост/клиент с 4/6/8 участниками. Проверить общий случайный вариант, читаемость и ориентацию UV, обзор вращающихся фигур, счёт движущегося парада, приватность выбора и восстановление движения. Общий экран может раскрывать чужие ответы несмотря на стены. Отдельно проверить получение приза одновременно с аварией, двойное касание и поздний вход на границе этапа.

Проверить загрузку и производительность большого числа неактивных вариантов. Ботам не приписывается понимание задач или риска; влияние 1–2 ботов на человеческий матч требует отдельной оценки.

Итог бэклога: **27 неотменённых игр, 21 со сборками, 6 нереализованных** — Broken Clock, Emergency Exit, Last Sale, Closing Time, False Alarm, Trap Operators. Ранее собранные пять игр резерва сохранены и не отменены.
