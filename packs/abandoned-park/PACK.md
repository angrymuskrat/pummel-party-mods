# Пак «Заброшенный парк» (Rusted Park)

Решения приняты 2026-10-21 (grilling, 2 раунда). Источник правды по возможностям редактора — `.claude/skills/pummel-party-mod-editor/reference/`.

## Тема

Парк аттракционов, брошенный после катастрофы в духе Fallout: ржавчина, выцветшая цирковая раскраска, радиоактивный пруд, маскоты без голов. Природа проросла сквозь рельсы, автоматы с сахарной ватой ещё включены. Тон — яркий абсурд оригинальной Pummel Party, не хоррор.

**Визуальные якоря** (всё из примитивов, процедурно):
1. Ржавое колесо обозрения — крутится (`Mover Component`, `Rotation Axis` Y/Z).
2. Сломанная карусель с лошадками — платформа-вращалка.
3. Американские горки с обрывами рельс.
4. Светящийся зелёный пруд (`Water Component`) — смертельная зона.
5. Маскоты-талисманы с отвалившимися головами — мишени и декор.

**Палитра:** ржавчина `#8B4513`/`#A0522D`, выцветший цирк `#C0392B`/`#F1C40F`, кислотно-зелёный `#7FFF00`, бетон `#7F8C8D`. Плоские цвета, минимум текстур.

**Не собирается в редакторе** (чтобы не возвращаться): зеркала и отражения; салки и «кто убил» (`On Weapon Hit`/`On Death` знают только получившего, `Hitter` у `Target` для минигр не документирован); управляемый транспорт (игрок всегда пешком); табло со счётом в мире (`Text Component` статичен); кооп и команды (места только индивидуальные); случайный выбор направления (случайны только интервалы, разброс и выбор префаба).

**Рекомендуемый порядок** (после 1 → 2): 3 Coaster Run → N2 Mascot Throne → 8 Sugar Rush → N1 Tilt House → 4 Mascot Range → N4 Human Cannonball → 9 Ghost Train → 10 Barrel Alley → N3 Balloon Pop → 7 Bumper Cars / N6 Teacups (после вердикта по карусели) → 5 Ferris Hold → N5 Searchlights. Логика: сначала дешёвые игры новых типов (захват зоны, удержание, меткость), дорогие и рискованные — когда плейтест карусели покажет, нравятся ли вращающиеся платформы.

**Порядок сборки:** 1 → 2 → 3. Сборка мышкой больше не нужна: моды генерируются кодом (`tools/pmgen.py`, пример `minigames/tickets/build_mod.py`), редактор служит для плейтеста и публикации. Ticket Rush прошёл плейтест полностью: билеты, пруд, jump pad, таймер.

**Адаптации:** редактор не открывает мини-игры базовой игры. «Адаптация» = шаблоны (3, 4, 7, 8, N2, N3) плюс пересборка любимых механик оригинала с нуля. Открытый вопрос: какие 2–3 мини-игры базовой игры хочется увидеть в теме парка — назвать, я проверю по каталогу, собираются ли они.

## Общие правила для спецификаций

- Логика только из `logic-catalog.md`; поля, которых вики не называет, помечены «проверить в редакторе».
- Переменных и условий в редакторе нет: эскалация сложности делается цепочкой `Start` → `Wait Action` → `Set Active Action`, а не счётчиками.
- Смертельные зоны: `Trigger Component` `On Enter` → `Kill/Destroy Action` на вошедшего игрока.
- Каждая спецификация заканчивается чеклистом плейтеста.
