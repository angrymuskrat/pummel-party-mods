# Ассеты пака «Заброшенный парк»

Всё генерируется кодом; скрипт лежит рядом с результатом, чтобы ассет можно было перегенерировать. Ограничения редактора: модели только `.obj` (≤ 65 535 вершин, возможное отражение по одной оси при импорте), текстуры `.png`/`.jpg` (назначаются через `Material Asset`, слот `Albedo`), звук только `.wav`.

Статусы: нужен → сгенерирован → импортирован → проверен в сцене.

## Открытые вопросы

- Текстуры не бесшовные: при `Wrap Mode` = `Repeat` на больших плоскостях будет виден стык. Если мешает — добавить в генератор зеркальное сведение краёв.

- Отражение по оси при импорте `.obj`: после первого импорта зафиксировать, какую ось зеркалить в генераторе.
- Лимиты размера текстур и длины звука на вики не названы — держать текстуры ≤ 1024², звук ≤ 10 с, пока не проверено.
