# Ассеты прототипов механик

Генератор: `generate.py`, Python 3.10+, стандартная библиотека и существующий Canvas из plan_view. Запуск из корня: `python packs/abandoned-park/assets/mechanic-prototypes/generate.py`.

- `question_0..23.png`: 24 карточки 768 × 384, данные из проверенного manifest Counterfeit Mascots. Одинаковые детали костюма не добавляют ложных отличий; номер выбора находится только на кнопке.
- `option_1..4.png`: номера кнопок 128 × 128.
- Остальные PNG: таблички 512 × 192 для поездки, фиксации ответа, результата, финиша и типов опасности.
- `questions.json`: условия и ответы 24 задач непрерывной серии.

Для сцены используются существующие `expansion/screen.obj` с исправленным U, `art-direction/surface_cube.obj`, материалы и профили освещения из art-direction, модели бочки, вагонетки с осями и колёсами, рельсов, фонового парка. Новые 3D-форматы и внешние зависимости не добавлены.

V3 использует шесть вариантов игрушек с разными ушами и пуговицами. Для каждого генерируются плитки MODEL и 1–4. В arcade_deck.json перечислены четыре показанные плитки и образец каждого задания. Из них сборщик определяет подделку. Генератор также создаёт 16 табличек PICK / FAKE и восемь заголовков с номером своей дорожки. Миниатюрные фигурки используют существующую модель mascot_target.obj.
