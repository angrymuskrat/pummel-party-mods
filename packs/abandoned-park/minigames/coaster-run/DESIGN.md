# Coaster Run / Горки без рельс

**Цель:** добежать до финиша по обрушенным американским горкам. Места — по порядку прихода; кто не добежал за 45 с, стоит ниже всех финишировавших, а между собой — по дальности (сколько рубежей прошёл).

| Параметр | Значение |
| --- | --- |
| Тип мода | Minigame с нуля (`build_mod.py` на `tools/pmgen.py`). Шаблон `Third Person Obstacle Course` — образец приёмов (триггеры-возвраты, финиш), не основа сцены |
| Игроки | 8 мест на линии старта (один общий спавн `Line`), баланс 4–6 |
| Длительность | 1 раунд, предохранитель `Round Duration (s)` = 45 (было 90, потом 60; прожарка 2026-10-25) |
| End Condition | `Timer` + `FinishMinigame` (как в шаблоне: 9) |
| Placement Condition | `Finish Order` |
| Player Type | `Third Person`; бег 6 м/с, прыжок 7 м/с при гравитации 25 → 0.98 м вверх, 3.4 м в длину |
| Health | `Use Health` выкл.; `Can Respawn` вкл., 2 с — только на случай страховочной зоны смерти |
| Punching | вкл., урон 0; отброс 5 м/с от бьющего + 3 вверх (`weaponHitTrigger`, схема Death Carousel) — столкнуть соседа с балки можно, убить нельзя |

## Пространство

- **Форма:** коридор с развилкой в начале, поворот на 90° в середине. Трасса ≈ 135 м: S1–S3 по +Z, сломанная петля поворачивает на +X, S5 по +X. Чистый бег ≈ 23 с, с прыжками и падениями 35–60 с.
- **Маршруты:** S2 — три балки-дорожки (x −2.6 / 0 / +2.6) с разным риском, между ними можно перескакивать (зазор 1.3 м). Левая — два разрыва по 2.4 м; средняя — без разрывов, но с двумя ржавыми пролётами; правая — один разрыв 3.0 м (на пределе прыжка) и короткие куски. Дальше одна дорога: подъём шириной 2.6 м — узкое место, там дерутся.
- **Зоны:** станция (безопасно) → рельсы над рвом (риск низкий, падение — потеря 3–5 с) → вагонетки над кислотой → подъём (толкучка) → петля над кислотой (риск высокий) → спуск, батут, финиш.
- **Ориентир:** колесо обозрения впереди справа (видно со старта и со спуска) и стоящий скелет петли у поворота.
- **Средний план:** низкие шпалы-барьеры на спуске (0.4 м, перепрыгнуть), вагонетки (выше прыжка — уворачиваться), бортики станции.
- **Мелочь:** во рву у лестницы и у стен — маскоты без голов, бочки, перевёрнутая вагонетка; у станции — фонари; у финиша — шахматная арка.
- **Движение мира:** игровое — 3 вагонетки, 2 качающиеся плиты, ржавые пролёты; фоновое — колесо обозрения (`Mover`).
- **Задник:** опоры горок под всей трассой, холмы и сухие деревья по кругу, пруд под второй половиной.
- **Метрики plan_view (2026-10-24):** см. раздел «Сборка кодом».

## Риски

- `Match Transform` на игроке по коду поддержан (`if (component is SimpleModPlayer) TeleportPlayer`), но в наших модах не проверялся. Запасной вариант — `Position Action` `Set`, как в шаблоне.
- `TeleportPlayer` не гасит скорость `CharacterMover`: падающий может «доехать» вниз ещё кадр. В шаблоне тот же приём работает.
- Движущийся триггер вагонетки против стоящего игрока — тот же непроверенный вопрос, что у метёлок Death Carousel.
- `Timer` у ржавых пролётов: идёт ли он во время заставки и сбивается ли, если цепочка длиннее интервала (6 с > 3.7 с цепочки — не должна).
- Боты на балках 1.3 м будут падать чаще людей — это ров и телепорты, не тупик.

## Чеклист плейтеста

1. Старт: все на станции в линию, сообщение «Рельсов нет. Беги!».
2. S2: с балки падаешь в ров, не умираешь; тебя переносит на станцию или на левую балку (п. 11). Перескок между дорожками работает. Средняя: пролёт скрипит, секунду мигает красным/жёлтым и пропадает на 2.5 с.
3. S3: вагонетка сбивает, оглушает и отбрасывает; упавший в кислоту появляется в начале S3 лицом вперёд, с искрами.
4. Подъём проходится бегом, на нём толкаются.
5. Петля: плиты допрыгиваются, качающиеся возят стоящего; падение с любой плиты, в том числе с последней и в прыжке к CP5, → вершина подъёма, а не CP5. Ржавые плиты мигают перед исчезновением.
6. Спуск: барьеры перепрыгиваются; батут перебрасывает через разрыв на финиш, без батута не допрыгнуть.
7. Финиш: надпись «… finished», конфетти, звук, игрока переносит в ложу, выйти из неё нельзя.
8. Все финишировали → конец раунда; не добежавшие к 45 с — ниже финишировавших, между собой по дальности.
9. Боты доходят хотя бы до петли.
10. Удар отталкивает и не убивает.
11. Падение в ров в первой половине S2 → на станцию, во второй → на левую балку у z 20 лицом вперёд; не соскальзываешь с балки сразу после переноса.
12. Правая балка переходит в обход вагонеток; обход проходится с одним прыжком 2.4 м; падение с него → начало S3. С конца обхода шаг влево на подъём.
13. Вагонетки по-прежнему ездят по полотну и не задевают обход.
14. Ощущения (записать): какую дорожку выбирали люди и почему; во сколько финишировал первый и сколько ждал последний; успевают ли за 45 с добежать хотя бы двое из четырёх (если нет — вернуть 55–60 с).
